# ASCII-схема блоков лендинга (wireframe)

Ниже - черновая ASCII-схема расположения блоков и контейнеров контента для лендинга ИП KUDRYASHOV PRO LAB 

#HEADER
+--------------------------------------------------------------------------------+
| HEADER                                                                          |
|                                                                                | 
| [LOGO] KUDRYASHOV PRO LAB     [Абонементы]  [Ваш город: Новокузнецк]    [Пробное занятие] [Меню | Войти] |
|          ШКОЛА ПЛАВАНИЯ                                                        |
| при нажатии на меню есть dropdown: тренеры, чемпионаты, лагерь                 |
+--------------------------------------------------------------------------------+

логотип - logo.png "KUDRYASHOV PRO LAB"     
пункт "абонементы " - при нажатии переносит на другую страницу (ссылка) 
кнопка "пробное занятие " - вызывает форму, сейчас форму делать не надо, сделай заглушку формы
сдвоенная кнопка "меню | войти " - "меню" это бургер-кнопка, при нажатии на нее вылезают три пункта меню: "Тренеры", "Чемпионаты", "Лагерь"
в правом верхнем углу надпись с локацией "ваш город: Новокузнецк" - при нажатии на этот пункт можно изменить свою локацию в popup. есть три доступные локации:  г. Новокузнецк, г. Кемерово, г. Новосибирск
header не должен постоянно висеть на экране

#mobile
Mobile (логика сжатия)
- Header: [Лого] [burger] [Записаться]
- Hero: 1 колонка; после текста — CTA; затем видео/изображение
- Вопросы в первых блоках — вертикальным списком
- Safety / Result / Team — по 1 колонке, карточки stacked
- Level system:
  [1 уровень]
  [2 уровень]
  [3 уровень]
  [4 уровень]
- Big service block — все сервисные карточки в 1 колонку
- Trainers / Pools / Reviews — горизонтальный свайп или 1 карточка в ряд
- Final CTA — компактный, кнопка full width
